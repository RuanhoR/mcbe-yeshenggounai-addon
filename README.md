# 野生狗奶 (YeShengGouNai)

> [!NOTE]
> 本项目已迁移至 [mcx-example-addon](https://github.com/RuanhoR/mcx-example-addon) monorepo 统一管理。本仓库保留作历史存档。

The `dist.mcaddon` is a MC addon base on [mbler](https://github.com/RuanhoR/mbler) and mcx.

Download page: <https://addon.wei.qzz.io/yeshenggounai/>

## Usage

### Self-host build

1. Download [Nodejs](https://nodejs.org)
2. Download pnpm

```bash
npm i -g pnpm
```

3. Download Deps

```bash
pnpm install
```

4. Build

```bash
pnpm build
```

### Download from webpage

1. Open the download page: <https://addon.wei.qzz.io/yeshenggounai/>
2. Select your Minecraft version and download the `dist.mcaddon`.
3. Open with Minecraft.

### Download from Github release

1. Download mcaddon file in Github Release
2. Open with Minecraft.
